# 🚗 UNIVERSO CARS 🏁

¡Bienvenido a Universo Cars!

Este proyecto es una página web dedicada a la famosa saga de películas **Cars**, de Disney y Pixar. Aquí podrás conocer más sobre las tres películas, sus personajes y sus historias.

## 🎬 ¿Qué encontrarás en esta página?

- **Inicio:** Presentación de Universo Cars.
- **Cars 1:** Conoce la primera película y sus personajes.
- **Cars 2:** Descubre la segunda aventura de Rayo McQueen.
- **Cars 3:** Conoce la última película de la trilogía.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- GitHub

## 📂 Estructura del proyecto

- `index.html` – Página principal.
- `cars1.html` – Página de Cars 1.
- `cars2.html` – Página de Cars 2.
- `cars3.html` – Página de Cars 3.
- `imagenes/` – Carpeta que contiene las imágenes del sitio web.

## 🎯 Objetivo

Crear un sitio web informativo y visualmente atractivo sobre la saga Cars, utilizando herramientas de desarrollo web.
